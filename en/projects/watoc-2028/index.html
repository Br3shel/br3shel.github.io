01 — The context

WATOC 2028 is a team web project developed at Cinvestav Mérida, presenting a theoretical and computational chemistry meeting and organizing information for its participants.

The portal brings together the congress introduction, venue information, accommodation, transportation, and guidance for prospective participants.

02 — My participation

I contributed to frontend and backend development as part of the team. My work covered the web interface and server-side services; the payment gateway was outside my contribution.

The scope described in this case belongs to the product developed by the team.

The team used Git and GitHub for version control and collaboration on the project’s code.

03 — Project scope

  • Informational website with congress, venue, and visitor service sections.
  • Registration and contact forms with field validation.
  • Backend modules for users, participants, and scientific abstracts, among other domains.
  • Geographic resources and practical information for staying in Mérida.

The interface uses React, JavaScript, and TypeScript with Material UI. The backend uses Django and Django REST Framework.

04 — The technical approach

Separating the interface from the API gives each layer distinct responsibilities. On the frontend, reusable components and React Hook Form support a consistent experience across pages.

On the backend, models, serializers, and views are grouped by domain. This approach organizes shared development and allows each part of the platform to evolve independently.

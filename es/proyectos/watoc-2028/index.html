01 — El contexto

WATOC 2028 es un proyecto web realizado en equipo en Cinvestav Mérida, orientado a presentar un encuentro de química teórica y computacional y organizar información para sus participantes.

El portal reúne la presentación del congreso, información de la sede, hospedaje, transporte y orientación para quienes desean participar.

02 — Mi participación

Participé en el desarrollo de frontend y backend como parte del equipo. Mi trabajo abarcó la interfaz web y servicios del servidor; la pasarela de pago queda fuera de mi aportación.

El alcance descrito en este caso corresponde al producto desarrollado en conjunto.

El equipo utilizó Git y GitHub para el control de versiones y la colaboración en el código del proyecto.

03 — Alcance del proyecto

  • Sitio informativo con secciones del congreso, sede y servicios para visitantes.
  • Formularios de registro y contacto, con validación de campos.
  • Backend organizado en módulos para usuarios, participantes y resúmenes científicos, entre otros dominios.
  • Recursos geográficos e información de apoyo para la estancia en Mérida.

La interfaz utiliza React, JavaScript y TypeScript con Material UI. El backend utiliza Django y Django REST Framework.

04 — El enfoque técnico

La separación entre interfaz y API permite trabajar en las dos capas con responsabilidades diferenciadas. En el frontend, componentes reutilizables y formularios con React Hook Form ayudan a mantener una experiencia consistente entre páginas.

En el backend, los modelos, serializadores y vistas se agrupan por dominio. Este enfoque organiza el trabajo compartido y permite evolucionar cada parte de la plataforma de forma independiente.
